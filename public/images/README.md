# Local artwork

`codebreaking-room.svg` and `turing-silhouette.svg` are original stylized vector placeholders created for this application. The figure is an illustrative 1940s scholar representing the fictionalized Alan Turing; it is not a photographic likeness. The equipment is atmospheric, not an engineering reconstruction of a Bombe.

Replace either file with independently licensed artwork if desired. Update the image URL in `Atmosphere.jsx` or `.room-art` in `App.css` for another file type. The approved flattened mockup is a design reference only and is never loaded by the running application. There are no remote image or font requests.
